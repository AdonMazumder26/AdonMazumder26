## About Me

I'm **Ruhul Mazumder**, a Computer Science and Engineering student at **Mymensingh Engineering College, Bangladesh**. I enjoy turning ideas into practical software, learning how systems work behind the interface, and building projects that connect technology with real-world problems.

- 🔭 **Building:** Full-stack web applications and project-based experiments
- 🌱 **Learning:** Better backend design, data structures and algorithms, and software engineering fundamentals
- 🧩 **Interested in:** Developer tools, interactive experiences, space technology, and useful products
- 🤝 **Open to:** Learning with other developers, thoughtful collaboration, and open-source contributions
- 📍 **Based in:** Bangladesh

> I care about more than making an interface look good. I want to understand the system behind it, make it reliable, and keep improving it.
