## 👋 About Me

I'm **Ruhul Ma Ani Mazumder**, a Computer Science and Engineering student at **Mymensingh Engineering College, Bangladesh**.

I enjoy building web applications, exploring how software systems fit together, and turning rough ideas into useful digital experiences. My interests sit at the intersection of full-stack development, problem-solving, and creative technology.

- 🔭 **Building:** Full-stack applications and project-based experiments
- 🌱 **Currently improving:** React, Node.js, API design, databases, and software engineering fundamentals
- 🧠 **Practicing:** Data structures, algorithms, debugging, and writing maintainable code
- 🪐 **Exploring:** Interactive space-history experiences and data storytelling
- 🎸 **Outside coding:** Guitar, percussion, singing, and the long-term dream of playing in a band
- 🤝 **Interested in:** Meaningful collaboration, open-source learning, and projects with a clear purpose

> **My approach:** understand the problem, build the simplest useful solution, then improve it with evidence instead of guesswork.
